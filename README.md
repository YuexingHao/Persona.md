# Persona.md

Between you and your agent, which one is more representative of who you really are?

## Repository Contents
- `Persona.md`: structured, stable persona profile used for task personalization.
- `Personal_Wiki.md`: human-readable "Wikipedia-like" profile page.
- `persona_trivia.html`: 15-question binary quiz game, User vs Persona Agent.
- `index.html`: concise entry page linking all persona assets.
- `evidence/`: dated evidence notes extracted from interactions.
- `examples/`: concrete profile examples.
- `snapshots/`: periodic persona snapshots.

## Update Process
1. Add a dated note under `evidence/` from new interactions.
2. Promote repeated signals into `Persona.md`.
3. Refresh `Personal_Wiki.md` and `index.html` when material changes.
4. Save periodic snapshot in `snapshots/`.
